# Чеклист развития продукта IMOEX Signals

Обновлено: 2026-04-18

Этот файл веду как живой продуктовый чеклист: что уже доведено до рабочего состояния, что сейчас в фокусе, и что делаем дальше.

## Уже сделано

- [x] Локальный preview и smoke-flows стабилизированы.
- [x] Workspace, dashboard, journal, preferences и delivery history доступны как отдельные user-facing страницы.
- [x] Русский язык включён по умолчанию, есть переключатель языка и inline-подсказка `Куда смотреть?`.
- [x] Добавлено боковое меню навигации между основными страницами.
- [x] Добавлена runtime-панель ролей моделей: видно `skeptic`, `arbiter` и другие роли, а также чей LLM используется.
- [x] Добавлена панель источников цен: видно провайдера, статус, владельца, freshness и последнее обновление.
- [x] Добавлен явный режим данных `live / snapshot / degraded feed`.
- [x] В интерфейсе показывается countdown до экспирации активного фьючерса.
- [x] В control panel показывается статус синхронизации справочника контрактов: `MOEX ISS / fallback`, время последней синхронизации и причина stale/fallback.

## Текущий фокус

- [x] Показать источник цены и свежесть данных рядом с основным торговым контекстом, а не только в control panel.
- [x] Добавить ручной workflow-статус сигнала: `наблюдаю`, `проверяю`, `игнорирую`, `эскалировать`.
- [x] Сделать user-facing decision log поверх журнала: что решил, почему решил, что должно измениться дальше.

## Следующие шаги

- [ ] Показать качество сигналов по root / horizon / model-role / provider.
- [ ] Добавить сравнение нескольких горизонтов в одном decision view.
- [ ] Добавить watchlist по сериям и сигналам.
- [ ] Добавить явные freshness-алерты, если root работает на degraded feed.
